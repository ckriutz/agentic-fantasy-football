# Agent Skills

| Skill | Trigger |
|-------|---------|
| `agent-bootstrap` | New or incomplete agent identity/game plan |
| `post-draft-review` | Draft completed; convert draft notes into in-season state |
| `weekly-reflection` | Completed week; evaluate results and plan upcoming priorities |
| `roster-management` | Set or optimize starters from the current roster |
| `weekly-player-management` | Evaluate and acquire players through waivers/free agency |
| `skill-smoke-test` | Explicit skills-system test only |
